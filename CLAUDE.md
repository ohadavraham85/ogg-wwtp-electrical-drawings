# OhadCad

Panel-layout and single-line diagram drawing tool, a standalone PWA.
Live at https://ohadavraham85.github.io/ogg-wwtp-electrical-drawings/ (GitHub Pages from `main`, no build step).

## Working with the owner
- Reply in Hebrew only, including progress messages, in plain simple language.
- Never ask for or accept passwords or Google-account access. When pointing to the Firebase console, say "אל תשלח לי סיסמאות או גישה לחשבון" and give click-by-click steps.
- The owner's email is private: never write it into this (public) repo.

## Layout
- `index.html`: the shell. It handles Google sign-in (Firebase Auth compat), the owner/approval gate, user management and bulk import. It hosts the drawing tool in an iframe and exposes `window.panelDesignsBridge`, which provides:
  - `me`, `list`, `info`, `load`, `save`, `remove`, `onChange`
  - `saveStatus(k, text, title)`: the tool's save state, shown in the shell's top bar.
  - `refresh()`: reloads the app (the tool's `appRefresh` saves first).
  - `menu()`, which returns extra items for the tool's drawer.
  - `topNav: true`: the shell's top row has the menu (☰ → the tool's `openDrawer`) and home (→ `homeOpen`) buttons, and its logo opens home too; the tool then hides its own `bMenu` / `bHome` (`body.shnav`) except on phones, where the shell row is hidden.
- `cad.html`: the drawing tool, a single file. It finds the bridge as `SH` (via `window.parent.panelDesignsBridge`). Opened directly, it saves to localStorage.
  - Parts live in `DEF[type]`.
  - Documents: `state.objs` / `state.alt`, and `state.tab` is 'panel' | 'sld' | 'both' | 'top'. The top view (plan) is a third document: while shown, `state.objs` = plan, `state.alt` = single-line, `state.pstash` = panel; otherwise the plan waits in `state.top`. Move with `splitAll` / `joinAll` (used by `switchDoc` and `withDoc`); `topObjs()`, `panelObjs()`, `sldObjs()` read any document. Sheets: `LAYDOC` has 'top' (`layoutT` / `originT`); the PDF prints the plan between front and single-line. Library tabs with `top:true` show only in the plan (`inDoc`); plan parts `troom` (box, carries its contents), `tdoor`, `twin`, `tcol`, `tstair`, `tcab`, `tequip`, `ttray`, `tsym`, `tnorth`, `tfurn` (furniture / shelving: kind `fk` in `TFK`, `furnDraw`; `bay` bays / doors / screens, `lv` shelf levels; also workstations `ws`, monitors `mon`, wall screens `tv` / `vwall`, `pc`; library tab "ריהוט ומדפים") (+ the existing `wall`, `label`, `callout`). Doors / windows dragged onto a room wall or a `wall` take its thickness, line and direction (`wallFit`, segments from `wallSegs`); a door's `p.sw` 'out' (default) / 'in' picks the side on a room wall and changing it refits the door in the same wall (`wallFit(o,1)` from the edit dialog; `p.wn` / `p.swl` remember the side on a free wall). The bottom bar's "מידות" (`data-sb=tdims`, only in the plan via `body.topv`; on unless `state.tdAll===0`, `tdOn`, `toggleTDims`) shows / hides every plan dimension (rooms' and equipment's own too) and draws every part's distances into the drawing (`allDims` appended in `objSVG`, so they print / export; laid out once per render by `allDimsLayout` → `ADIC`: deduped, longest first, labels moved along / beside their line to avoid each other, parts' bodies and their own blue dimension numbers; doors / windows also get their opening width). Distances run to the nearest neighbour (`PLAN_OB` parts' `bodyBox`) or the wall. A selected plan part always shows these distances (`selDims` → `SDIMS`; doors / windows via `wallOf`); tapping a distance pill (`data-ddim`, pre-handler on `svg`) types a value and moves the part (`sdimEdit`, entries carry axis and sign). While dragging in the plan, live distances (`DDIMS` from `dragDims`, drawn by `ddSVG` with `shpTag` pills): a door / window to its wall's ends (`WFG` from `wallFit`), other parts to the room's inner faces. Dragging in the plan snaps a part's box onto a room's inner wall faces / corners and walls' faces, with guides (`roomSnap`, `roomInner`). Equipment (`tcab`, `tequip`, `tstair`) draws its width / depth (`p.dm`, `bxDims`, `eqDimG`, `eqExt`). The library has one room item, drawn with two clicks like a shape (outer corners; the live pills show the inner size, `shpWt`); double-click edits its name in place (`roomNameEdit`, also a plan cabinet's text box `p.tag` — `tcab` has `dk` '1' / '2' doors, `tcabDbl`); double-click on a drawn dimension number (`data-rdim` w / h, remembered on pointerdown in `RDIM`) edits that size in place (`ownDimEdit`). A room draws its own inner dimensions (`p.dm`, `roomDims` / `roomDimG`). Doors, columns, symbols and the north arrow resize by box too (`fromBox`; a resized door / window refits its wall). A board's text uses `tagBox` (shrinks, wraps to two lines). DEF hooks: `fromBox(o,w,h)` turns a dragged box size back into the part's params (room walls, cabinet door swing); `ext(o)` pads the bounds for fit / export (`boundsX`). DEF entries may give `sel` (key → [[value,label]]), `lbl` (key → label) and `num` (numeric keys) for the generic edit dialog.
  - Library: `LIB`.
  - Templates: `TEMPLATES`. A drawing opened from a template carries `state.tpl` (= `tplHash()`); `doAutoSave` skips it while unchanged, so examples stay out of the shared folder until edited.
  - Autosave: `scheduleSave` / `doAutoSave`. The bridge's `save` now waits up to 8 s for the server: a refusal (rules, or `too-big` over ~1 MB, `MAX_DESIGN`) rejects and rolls the local list back; no answer returns `pending` (offline, sent later). Devices stay in step: `epd.cloudBase` = `{id, at, h}` (the saved version this device's copy is based on, `baseStore` / `baseInit`); `cloudSync` (at start, on the bridge's `onChange`, on return to the front) loads a newer save made elsewhere — also by the same user on another device — into the open drawing, keeping unsaved local changes as a device backup (`localBackup`) and as a separate drawing in the shared folder ("<name> (שינויים ממכשיר אחר שלא נשמרו)"); with no known base stamp it never replaces what is on screen (adopts the folder's stamp instead); `openCloudDoc` sets `cloudStamp` / base at once; `doAutoSave` saves as a copy whenever the folder's `updatedAt` moved past `cloudStamp`. On failure the tool shows the reason once (`LAST_SAVE_ERR`), sets the save state to error, retries in 20 s and keeps a copy in this device's projects as "<name> (גיבוי)" (`localBackup`).
  - Home screen (dashboard) `#home`: `homeOpen` at start once per session (sessionStorage `ohadcad.homeShown`, not for a `?d=` link; cleared before a settings reload) from the drawer tile "מסך הבית" and the top-bar house button `bHome` (next to the menu, also on phones); the open drawing with a preview, new / template / all drawings / library, search (`homeFilter`), "opened lately" from `ohadcad.recent` (`recentAdd` on `openCloudDoc` / `setCloud`, synced in `SYNC_KEYS`), the folder's latest updates and counts; previews `thumbOf` (draws a drawing's own parts with `objSVG`, state swapped in, cached in `HTHC` by id + updatedAt); `homeClick`, `homeClose`, Esc closes. The drawings span the full width (`.hwrap` up to 1680 px); settings rows `data-hs` (app colour, look, language, font / size, toolbar buttons, connection points, axes, sync check) and the shell's account items `HSM` from `SH.menu()` sit in a side panel `.side` that the ⚙ button (`data-h=set`) slides in (`#home.sopen`, shade / ✕ / Esc close it; `homeOpen(1)` keeps it open after a toggle).
  - Drawer menu: `openDrawer` — collapsible groups (`.dsec`, open state in localStorage `ohadcad.dsec`) of icon tiles (`.dt`, icons from `IC` via `ico`) with short names; the full explanation is the tile's tooltip; toggles get `.on`. Shell items come from the bridge `menu()` as `[label, fn, icon?]` under "חשבון".
  - Dimensions: part type `mdim` (`mdGeom`, `setMeas`); ends may be pinned to a part (`of`, `u`, `v`; `fx`/`fy` = on a box edge, follows resizing). A shape's own dimensions (`p.sd==='1'`) are turned into pinned `mdim`s on `commit` (`shapeDimsToMd`), so there is one kind of dimension; tapping one opens its panel (length edit `mdSetLen`, delete).
  - Layouts (production sheets): `state.lays` = `[{id,d:'panel'|'sld',name,paper,orient,scale,org}]`; the shown one per document mirrors into `state.layout` / `state.layoutS` (with `lid`) and its corner into `state.origin` / `state.originS` (`laySync`, `layShow`, `layWith`). Drawn on its own layer `#ulay` (`renderUlay`), only placeholders in `#world`; exports include it only with `exp:'1'`. Built each time from the panel parts: every part is a box whose front is its own 2D picture (`objSVG` → texture), depth per kind `v3Depth` / `V3DEP`; cabinets, enclosures and CI boxes get walls and doors that swing (parts with `front` ride the door). Parts standing on their own are extruded from their picture's outline (`sil` / `solid`, depth `v3Free`; light poles add a round shaft; motors and pumps `emotor` are a real model `motor3D` built from `motG`; flow meters `kflow`, valves `mvalve` / `hvalve` and fittings `hfit` are models on their pipe axis `inline3D`), cables / conduits / pipes are tubes along their route (`tube`), notes and tags lie flat (`V3FLAT`). Everything is centred on the drawing's plane (z=0; boards in a group at -D/2); floors, walls and pits (`V3CIV`) run the room depth `RD`. Tapping a part selects it (`OBJ`, `reg`, `choose`): `p.z3` moves it forward (+) / back (−) in mm, `p.d3` overrides its thickness (rebuilds the scene, keeping the view); both are also fields `f_z3` / `f_d3` in every part's edit dialog. Axes: X right, Y up, Z out of the plate (red/green/blue), big ones at the model corner (`V.axes`, button "צירים") and a corner compass rendered by `draw`. Uses `vendor/three` (three.js r160), loaded on first use.
- `sw.js`: offline cache. Pages and `i18n/` are network-first with `cache: 'no-cache'`; other assets are stale-while-revalidate.
- `manifest.webmanifest`, `icons/`, `favicon.ico`: the official OhadCad brand kit (amber "O" ring + crosshair icon, white/amber wordmark for dark backgrounds, amber/dark wordmark for light ones). Colors, fonts (Heebo/Inter/JetBrains Mono) and style are in `icons/wordmark-dark.svg` / `icons/wordmark-light.svg` and documented in the brand kit's own README (not kept in this repo) — the live palette is in both `index.html`'s and `cad.html`'s `:root` CSS variables.
- `vendor/firebase/`: firebase 12.19 compat bundles (app, auth, firestore).
- `vendor/three/`: three.js r160 (three.min.js), loaded only when the 3D view opens.
- `vendor/qrcode/`: qrcode-generator 1.4.4 (MIT), loaded with cad.html for the QR part.
- `i18n/en.js`: the English dictionary for the app's frame.
- `vendor/pdfjs/`: pdf.js 3.11.174 (pdf.min.js + worker), loaded only when a PDF is imported as a background.
- `LICENSE` (proprietary), `THIRD_PARTY_NOTICES.md`, `legal/` (Hebrew drafts of terms, privacy, accessibility — not linked until approved; then list them in `LEGAL` in `cad.html`, shown in the drawer's "אודות" dialog `aboutDialog`), `docs/COMMERCIAL.md` (commercialisation plan).
- The title-block default logo (`DEFAULT_LOGO`, the owner's organisation) is used only for the owner (`defLogo()`, bridge `me().owner`).
- Version history: `ohadcad_designs/{id}/versions/{auto}` = `{name,data,parts,savedBy,savedByEmail,savedAt,keptAt}`. The shell's `save` keeps the previous content (`keepVersion`) when the design's `verAt` is 10+ min old or another user saved it, and trims to 40; bridge `versions(id)`, `version(id,vid)`, `snapshot(id)`. The tool's drawer tile "גרסאות" (`versionsDialog`): restore in place (snapshots the current first) or open as a copy. Needs the `versions` rules in `firestore.rules` published.
- Recycle bin: the shell's menu item "לוחות שנמחקו — שחזור" (`trashDialog` in index.html) lists `deleted: true` designs and sets `deleted: false` to restore. A `?d=` link is cleared from the address bar once opened.
- `firestore.rules`: the source of truth for the rules. There is no CLI access. After changing it, the owner must paste it into Firebase Console → Firestore Database → Rules → Publish.
- `archive/`: the old "אינדקס תוכניות חשמל G-WWTP" app. It is read-only and still points at its old Firebase project.

## Firebase (project `ohadcad`)
Firestore collections:
- `ohadcad_meta/owner`: `{uid, email, label}`. Claimed once by the first sign-in.
- `ohadcad_users/{email}`: `{approved, label}`. Managed by the owner.
- `ohadcad_requests/{email}`: access requests.
- `ohadcad_designs/{id}`: `{name, data (JSON string of the tool state), parts, createdBy, createdByEmail, createdAt, updatedBy, updatedByEmail, updatedAt, updatedDevice, deleted}` — `updatedDevice` is set on every save from `deviceName()` in index.html (e.g. "טלפון Android · אפליקציה", "מחשב Windows · דפדפן"), returned by `info`, shown on the home screen, in the open dialog and the project properties; versions keep it as `savedDevice`.
  - Deletion is soft (`deleted: true`), and only the creator or the owner may do it.

## Releasing
1. Bump `VERSION` and `WHATS_NEW` in `index.html` (a one-line Hebrew summary of this release, shown at the bottom of the sign-in screen), and `CACHE` in `sw.js`.
2. Commit, push the working branch, then push it to `main`.
3. Check the "pages build and deployment" run via the GitHub MCP actions tools. github.io itself is not reachable from the sandbox.

## Testing
Serve the folder (`python3 -m http.server`). Load `cad.html` inside a harness page that defines a fake `panelDesignsBridge` (in-memory store plus `menu`), then drive it with Playwright.
